#  🔐  Vaultic - Password Manager (Local-First, Offline)

>  🚧 Work in Progress - a learning project built to demonstrate secure
> Software design, encryption, and professional Python engineering practice.

## Overview
A fully offline, local-first password manager written in Python from scratch. Built to practice layered architecture, cryptography, secure authentication, CRUD design, and real-world software engineering workflows (Git branching, PR discipline, pre-commit hooks, testing).

## Tech Stack
- Python 3.11+
- `cryptography` - encryption & key derivation
- SQLite - local encrypted storage
- `click` - CLI interface
- `pytest` - testing
- `pre-commit`, `black`, `ruff`, `mypy`, `detect-secrets` - code quality & security tooling
